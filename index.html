Use it in Pi

  1. Save the downloaded JSON in your themes folder.
    macOS / Linux / WSL
    ~/.pi/agent/themes/
    Windows
    %USERPROFILE%\.pi\agent\themes\
  2. Run /reload, then select your theme in /settings.

Your background selects a light or dark palette, but the exported theme won't change the terminal background itself. If you set PI_CODING_AGENT_DIR, use its themes/ folder instead. Your browser cannot install into Pi automatically.
